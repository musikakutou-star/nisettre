# 要件定義書
## プロジェクト概要
料理のレシピを共有するサイト
ターゲット層は主婦・若い女性
## イメージカラー
フレッシュな配色(緑ベース)
## 機能
ログイン
レシピ投稿(写真)
  - 料理名
  - 写真
  - 材料・分量
  - 手順
レシピへのコメント欄
SNS共有
全レシピからのレシピ検索・レシピ内容表示
投稿したレシピ一覧・編集・削除(どこから削除するかは未検討)

## 画面一覧
ログイン
サインアップ
ホーム
検索
マイページ

投稿一覧(削除ボタン)
投稿
編集(削除ボタン)

投稿されたレシピ表示  
レシピの検索結果

* ユーザー設定
* マイページ
* ログアウト
